# 🍔 Somato - Food Delivery App

A full-stack food delivery application inspired by Zomato. This project allows users to browse restaurants, view menus, manage a cart, and place orders securely. It also features a protected Admin Dashboard for managing users.

## 🚀 Features

- **User Authentication:** Secure Login/Signup.
- **Restaurant Discovery:** Browse restaurants by city or "Best of" collections.
- **Admin Dashboard:** Secure area to view and delete users.
- **Cart & Checkout:** Add items to cart and place orders.
- **Responsive Design:** Optimized for Desktop and Mobile.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **State Management:** React Context API
